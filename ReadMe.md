# 🏷 To-do-list

A simple terminal-based to-do-list program that stores tasks, prevents duplicate tasks and shows the date when the task was created.

## 📌 Problem Statement

Keeping track of daily tasks can be overwhelming especially in todays chaotic and busy world full of so many distractions. This application solves that problem by providing a simple and clean terminal interface to store tasks, no fluff.

## 🎯 Project Goals

-Allow users add new tasks
-Store Tasks
-List all Tasks
-Delete Tasks
-Clear Tasks

## 🛠 Tech Stack

**Programming Language**
-Bash

**Bash Commands**

-Case
-sed -i
-nl
-grep

## 🖥 Features

-Task addition
-Task deletion
-Time Stamp

## ⚙ Installation and setup

Clone the repository:

```bash

git clone https://github.com/swiftnathanx2/Terminal-To-Do-List.git

cd To-Do-List
Install dependencies:
npm install
Run the project:
npm start
chmod +x to-do.sh
```
